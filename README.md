# nyansatek.market

NYANSATEK's marketplace: customers browse and order from every shop that lists products on it.
Static site on GitHub Pages; data comes from the nyansatek-pos Supabase project (public catalogue
functions only). Addresses use `#` (for example `/#/c/drinks`) because GitHub Pages has no URL rewrites.

- `index.html`: the marketplace (home, categories, search, shops, products, cart, checkout, tracking, my orders)
- `rider/`: rider and driver app
- `ops/`: NYANSATEK team dashboard
